# Unicorn Architecture Website

This project is a website for **Unicorn Architecture**, an architectural studio that presents its portfolio, services, and contact information.

The website showcases the company's architectural projects such as private houses, residential buildings, office buildings, railway stations, and logistics centers. It allows visitors to explore the studio's work, view detailed project pages, and get in touch with the architects.

## Purpose of the Project

The goal of this project is to create a modern, fast, and minimalistic portfolio website that presents the architectural work of the studio and allows potential clients to easily explore projects and contact the company.

## Tech Stack

This website is built using **Astro**, a modern web framework focused on performance and static site generation.

Key features of the project:

- Static site generation
- Component-based architecture
- Fast loading performance
- Simple and maintainable structure
